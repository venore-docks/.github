# .github

Arquivos de comunidade e de perfil da organização **venore-docks**.

- [`profile/README.md`](profile/README.md) — o que aparece na página da organização.
- [`CONTRIBUTING.md`](CONTRIBUTING.md), [`SECURITY.md`](SECURITY.md),
  [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — herdados por qualquer repo da org que não tenha
  os seus próprios.
- [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) e
  [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) — templates padrão de issue e PR.

Editar aqui muda o padrão para todos os repositórios da organização de uma vez.
