# Política de Segurança

## Versões suportadas

Recebe correção de segurança a linha `main` do core e a última release de cada pacote
`@venore/plugin-*` / `@venore/theme-*`. Forks de site são responsabilidade de quem opera a
instância.

## Reportando uma vulnerabilidade

**Não abra uma issue pública.**

Use **Security → Report a vulnerability** (GitHub Private Vulnerability Reporting) no repositório
afetado, ou envie e-mail para **adoniran.bail@erasto.com.br** com:

- o repositório e a versão/commit afetados;
- passos para reproduzir ou uma prova de conceito;
- o impacto que você consegue demonstrar.

## O que esperar

- **Confirmação de recebimento:** em até 3 dias úteis.
- **Avaliação inicial e severidade:** em até 10 dias úteis.
- **Correção:** conforme a severidade; coordenamos a data de divulgação com quem reportou.

Pedimos que a falha não seja divulgada publicamente até uma correção estar disponível. Créditos
a quem reportar, se desejado.
